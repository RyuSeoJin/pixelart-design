# 픽셀 아트 최종 리소스

이 폴더만 복사하여 사용합니다. `manifest.json`의 `assets`에서 식별자와 버전을 정확히 선택합니다.
각 항목의 `path`는 이 폴더 기준 `asset.json` 상대 경로입니다. `asset.json` 안의 PNG 경로는 해당
파일이 있는 폴더 기준입니다. `default_file`이 기본 이미지이며 `filter`는 최근접 표시를 뜻합니다.
캐릭터는 왼쪽 위 기준 픽셀 좌표 `pivot`과 `facing`, 애니메이션은 `animations`를 함께 읽습니다.

PNG의 알파를 그대로 사용합니다. 16 작업 아이콘은 16·32·48·64px 파일 중 실제 표시 크기에 맞는
파일을 선택합니다. 기존 버전은 수정하지 않으며 최신 버전으로 자동 교체하지 않습니다.

현재 등록된 최종본은 없습니다. 빈 목록은 오류가 아니며 미승인 예제를 대신 표시하지 않습니다.
