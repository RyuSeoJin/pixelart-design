# pixelart-character — 문서 템플릿 카탈로그

중앙 모듈에 일러스트 기준서 템플릿이 없어, 사용자 승인으로 이 프로젝트에 전용 서식을 둡니다.
중앙 마스터 CSS v1.13의 기존 컴포넌트만 사용합니다. 중앙 규칙과 마스터는 수정하지 않습니다.

| 번호 | 템플릿 | 입력 → 산출 | 버전 |
|---|---|---|---|
| 01 | `01-illustration-rules.html` | 확정 사양·관찰 기록 → 모든 캐릭터가 준수할 일러스트 제작 기준서 | v1.0 |
| 02 | [캐릭터 설정 공통 템플릿](../spec/design/character-settings-template.md) | 캐릭터 고유 설정 → source/{캐릭터}/character.md, 공통 제작 규칙은 참조 | v1.0 |

## 섹션 구조와 사용법

적용 범위 → 고정 사양과 비율 → 얼굴·머리카락 → 실루엣·의상·소품 → 외곽선·색·명암 → 제작 순서 → 검수 → 근거·미확인 목록 순서입니다.
독자가 먼저 변경할 수 없는 기준을 알고, 큰 형태에서 세부 표현으로 작업한 뒤 같은 기준으로 검수하도록 구성합니다.

컴포넌트는 마스터의 `hero`, `badge`, `section`, `tbl`, `callout`, `diagram`, `swatch`, `checklist`를 재사용합니다.
새 CSS 컴포넌트와 변형은 없습니다. 그림은 설명용 자체 SVG이며 남의 작품을 삽입하지 않습니다.
규칙마다 식별자·준수 내용·확인 방법을 두고, 관찰값과 제작 규정을 명확히 구분합니다.

## 저장과 정본

제작 규칙서는 `spec/design/`에 HTML로 저장하며 그 HTML 본문이 정본입니다. 서식에 본문 사본을 두지 않습니다.
프로젝트 구조 설정에 `specification`으로 등록하고, change-log 현행 기준에서 모든 캐릭터 작업의 필수 읽기 자료로 지정합니다.
산출물에는 마스터 CSS 전체와 사용 글꼴을 내장합니다. 서식은 중앙 CSS를 상대 경로로 참조합니다.
