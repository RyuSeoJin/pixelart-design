여기 수치는 기대값으로 쓰지 않습니다 — 채택한 값은 `reference/adopted-values.md`, 확정값은
`spec/design/pixel-spec-portrait.json`(초상화)에 있습니다.

## 공통으로 보인 것

| 항목 | 관찰 |
|---|---|
| 비율 | 대부분 5~7등신. 가랑이가 키의 절반 근처 |
| 머리 크기 | 약 15~18px? — 눈 · 입을 따로 그릴 만한 크기 |
| 눈 | 폭 4~6px?, 홍채 명암 · 하이라이트 · 윗 속눈썹 선이 보임 |
| 색 수 | 약 40~60색 이상? — 램프 단계가 많고 전이가 부드러움 |
| 외곽선 | 한 색이 아니라 부위마다 다른 어두운 색. 광원 쪽은 선이 거의 없음 (셀아웃) |
| 광원 | 대체로 왼쪽 위 |
| 표현 | 옷 주름 · 머리카락 가닥 · 손가락 덩어리까지 보임 |
| 구성 | 전신 1장이 대부분. 6번은 앞 · 뒤 · 얼굴 확대를 한 장에 모은 설정화 시트 |
