# 캐릭터 설정 공통 템플릿

개별 character.md에는 고유 설정과 승인된 예외만 기록합니다. 현재 파일·승인 상태·검수 근거는 같은 폴더의 production-status.md에서 관리합니다. 제작 방식·파일 규격·폴더·승인 절차는 아래 정본을 참조하고 복사하지 않습니다. 미정 항목은 미정으로 남기고 추천안을 구분하여 사용자에게 확인받습니다.

- [공통 제작 규칙서](pixel-art-6head-illustration-guide.html): 시점 정의, 표정 변경 범위, 제작·검수·승인 및 저장 절차
- [필드 사양](pixel-spec-field.json) · [초상화 사양](pixel-spec-portrait.json): 수치와 제작 메타데이터

아래 설정 항목을 `source/{캐릭터}/character.md`에 채우고, 승인·검수·작업 상태 항목은 같은 폴더의 `production-status.md`에 채웁니다. 해당 없는 항목은 없음으로 기록합니다. 공통 규칙의 승인된 예외만 근거와 적용 범위를 남깁니다.

## 사용 순서

이 서식으로 고유 설정·미정 사항·추천안을 채우고 시점 목록과 제작 순서를 함께 제시해 승인받습니다. 승인된 설정을 기준으로 생성하기 전에 [제작 자료 확인 절차](pixel-art-6head-illustration-guide.html#production-read-gates)를 적용합니다. 승인·제작·검수 절차의 정본은 해당 규칙서이며 이 템플릿을 채웠다는 사실만으로 생성하거나 설정을 확정하지 않습니다.

- 성격·평소 인상: 미정
- 계승할 설정·변경할 설정·추가하지 않을 요소: 미정

- 헤어의 길이·색·덩어리·가르마·땋은 구조: 미정

- 주색·보조색·강조색: 미정
- 부위별 색상표 경로·버전 및 기본색·밝은색·그림자색·깊은 그림자색·외곽선의 색상값: 미정
- 방향별 환경광·효과 색상 예외 및 승인 근거: 없음
- 소품·장식의 개수·형태·크기·신체 좌우: 미정

## 승인 원본과 검수 연결

- 승인된 외형 기준 8종의 목록·버전·승인 기록 경로: 미정
- 출력별 직접 기준 시점과 보조 기준의 대응: 미정
- 현재 작업의 부위별 검수 기록과 비교본 경로: 미정

매 작업 전 [승인된 8종 기준의 필수 대조](pixel-art-6head-illustration-guide.html#approved-view-review)를 확인합니다. 위 경로만 기재하고 실제 이미지를 열지 않은 상태는 검수 완료가 아닙니다.

## 좌우 이동용 공통 구조 연결

- 공통 구조표 경로·버전·해시 및 치수 측정 상태: 미정
- 직접 기준으로 사용할 승인된 좌우 시점 쌍: 미정
- 신체 기준 좌우 비대칭·가림 목록과 승인된 치수 예외: 없음
- 좌우 실측·윤곽 겹침·방향 교대 검수 기록: 미정

공통 제작 방법은 규칙서의 [좌우 공통 구조와 제출 조건](pixel-art-6head-illustration-guide.html#direction-pair-contract)을 따릅니다. 미측정 값을 임의로 채우거나 경로만 적고 통과 처리하지 않습니다.

## 캐릭터별 시점 선택

- 일러스트용 front의 몸·얼굴 회전 방향·각도·시선: 미정
- 일러스트용 head_front의 몸 방향과 정면을 보는 고개·목 연결: 미정
- 기준 자세의 캐릭터별 선택: 미정
- 방향별로 특히 확인할 비대칭 요소: 미정

공통 시점 목록과 파일명을 다시 정의하지 않습니다. 캐릭터별 변경 요청이 있으면 아래 예외·승인에 기록합니다.

## 일러스트 후보와 선택

- 포즈 후보 용도와 캐릭터에 어울리는 서로 다른 동작 4종의 글 설명·선정 이유·유지할 외형: 미정
- 선택·승인된 포즈 식별자·글 설명·제안 경로·버전·해시·승인 기록: 미정
- 승인 포즈 기반 front/head_front 두 시안과 부모 포즈 연결: 미정
- 선택한 후보 식별자·확정 경로·버전·해시·승인 기록·용도: 미정
- 선택 기록: 캐릭터 루트 illustration-selection.json, pose_selections와 selections를 분리하며 선택 전에는 각각 빈 목록
- 표정 제작 기준: 선택 기록의 승인 후보. 기준 시점 8종 승인·포즈 승인·파생 일러스트 승인은 구분합니다.

- 승인 대상·버전·근거·범위·허용된 다음 단계: 미정
- 승인된 공통 규칙 예외: 없음
- 미정 항목·추천안·확인할 질문: 미정

## 파츠 제작 시 기록

[파츠 분리와 원본 보존](pixel-art-6head-illustration-guide.html#parts-preservation)에 따라 외형 기준·출력 정지본의 경로와 해시, 정지본 승인, 재합성 비교 결과, 가려진 면의 복원 근거, 관절·재생 검수 상태를 구분해 기록합니다. 사용자 지적을 받은 정지본·동작은 기존 승인 이력을 지우지 않고 현재 재작업 대상으로 표시합니다.

[기준 외형·좌우 디자인·재합성 검사](pixel-art-6head-illustration-guide.html#pair-design-review)의 부위별 비교 그림, 공통 치수·문양 부착점·재질색, 허용한 방향 차이와 이유, 수정 전후 해시·변경 영역, 세 검사 및 실제 재생·사용자 승인 상태를 검수 기록에 연결합니다. 개별 설정에 공통 검사 방법을 다시 복사하지 않습니다.

[재질별 색 혼입 검사](pixel-art-6head-illustration-guide.html#material-region-review)에 사용하는 부위 영역·허용 색·정상 경계 예외·검사 도구·결과·확대 비교 경로를 기록합니다. 자동 검사 범위와 시각 검수 범위를 구분하고, 같은 재질의 양방향·전체 프레임 재검수 여부를 남깁니다.

## 최종 수정본 제출 기록

[윤곽과 최종 수정본 재검수](pixel-art-6head-illustration-guide.html#contour-final-review)에 따라 아래 기록의 경로를 연결합니다. 공통 절차를 캐릭터 설정에 복사하지 않습니다.

- 적용 규칙서 버전, 외형 기준·최종 출력 파일·파츠 원본의 경로와 해시
- 검사 영역·검사 도구의 경로와 버전 또는 해시, 해당 캐릭터·자세에 적용 가능한 범위
- 얼굴·턱·목·엄지·손끝·소매·문양·옷단·꼬리별 색 혼입·외곽선·형태 판정
- 수정 영역과 인접 부위·반대 방향의 재검수, 동작일 때 해당 전체 프레임 검수
- 최종 PNG의 1배·정수배 확대·밝은 배경·어두운 배경 비교 근거
- 수정 영역 밖 변화·재합성 검사 결과, 자동 검사·시각 검수·사용자 승인·동작·엔진의 각각의 상태

현재 자세에 한정된 검사 영역을 다른 자세의 완료 근거로 재사용하지 않습니다. 검사에서 발견한 오류는 수정 후 새 출력 해시로 재검사하고, 과거 통과 기록의 대상 파일을 바꾸지 않습니다.

## 애니메이션 제작 기록

[애니메이션 기본 제작 도구](pixel-art-6head-illustration-guide.html#sprite-gen-idle)에 따라 sprite-gen 버전·사용 기능·승인 입력과 해시·실행 경로·프레임 수·시간·동작 설정을 연결합니다. 호흡은 강도·가로 변형·횟수·지연과 자동 인식 검토·수정 근거를 기록합니다. 방향별 값과 공통 타이밍, 원본과 달라진 부위, 얼굴·문양·색·접지·반복 재생·엔진 검사 상태를 구분합니다. Aseprite 부분 수정이 있으면 대상과 이유를 남깁니다.

## walk 설계와 회차별 검수 기록

[walk 제작·수정·반복 검수](pixel-art-6head-illustration-guide.html#walk-production-review)를 적용합니다. 캐릭터별 production-status.md에는 아래 기록 파일의 경로를 연결하고 공통 절차를 복사하지 않습니다.

| 기록 | 필수 항목 |
|---|---|
| 제작 계획 | 입력 승인·해시, 방향, 실제 전달 참고 이미지·프롬프트, 고정 배율·기준점, 프레임 역할, 타이밍, 미정 치수 |
| 원본 비교 | 얼굴·머리·후드·문양·손·꼬리·재질별 비교 영역, 위치 정렬 방법, 허용 변화와 이유, 증거 파일 |
| 수정 회차 | 방향·프레임·부위, 원인, 수정 방법·영역, 수정 전후 해시, 이전 회차와의 차이 |
| 다리 연속성 | 가까운/먼 다리 식별, 관절·발 경로, 설계 좌표와 실제 관찰 구분, 반주기 교대·8→1 연결, 폭·길이·가림 변화, 연결부·잔여 도트 검사 |
| 중간 공유 | 미완성 표시, 방향·버전, 변경 전후 미리보기, 변경 내용·남은 문제, 승인 후보와의 구분 |
| 재검수 | 해당 부위·인접 부위·전체 주기·반대 방향 결과, 실제 반복·속도·연결·방향 전환 관찰 근거 |
| 제출 | 필수 항목별 판정·근거, 미검수·수정 필요 목록, 사용자 승인·엔진 검사 상태 |

판정은 `pending`, `needs_revision`, `pass`로 구분하고 사용자 승인은 별도 기록합니다. 근거 없는 항목은 통과로 두지 않습니다. 정지 자세용 고정 좌표 검사 영역을 움직인 부위에 그대로 적용하지 않습니다. 회차 번호만 올리거나 전체 점수로 개별 실패를 가리지 않습니다.

## 모든 애니메이션의 제출 기록

제작 규칙서의 `animation-common-review`를 모든 동작에 적용합니다. 캐릭터별 입력·방향·보존 부위·관절과 부착점·동작별 접촉 조건·프레임 시간·반복 여부를 먼저 기록합니다. 윤곽의 공간적 연결과 프레임 간 변화, 신체·의상·소품의 가림, 전체 리듬, 제작된 다른 동작으로의 동일 오류 전파 여부를 검사합니다. 임의 고정 좌표를 공통 규칙으로 복제하지 않습니다.

문제별 방향·프레임·부위·원인·수정·재검사 결과와 원본 대조 근거를 남깁니다. 실제 재생을 관찰하지 못한 항목은 미검수로 기록합니다. 사용자 승인·파일 검사·엔진 검수는 별도 상태로 관리하며 승인된 파일은 해시와 승인 범위를 함께 보관합니다.

## 문서별 저장 책임과 현재 상태 서식

과거 작업 기록을 다음 제작의 지시로 읽지 않도록 아래 역할을 나눕니다. 기존 설정·검사 항목은 유지하며 저장 위치를 구분합니다.

| 문서 | 기록할 내용 | 갱신 방식 |
|---|---|---|
| 공통 제작 규칙서·사양 JSON | 모든 캐릭터의 방법·판정 기준·수치 | 공통 결정이 바뀔 때 갱신 |
| character.md | 기본 정보·외형·복식·문양·표정 인상·시점 선택·승인된 예외·미정 설정 | 고유 설정 변경 시 갱신 |
| production-status.md | 적용 규칙 버전·승인 원본·현재 검토본·선택 포즈·검사 결과의 경로·남은 검수 | 현재 상태로 교체, 과거 상태 누적 금지 |
| work의 계획·검수 기록 | 해당 캐릭터의 좌표·변형량·프레임 역할·부위 검사·회차별 증거 | 버전·대상 해시별 보존 |
| 프로젝트 change-log·remaining-work | 작업 이력·다음 작업 | 이력 누적·완료 할 일 제거 |

production-status.md는 적용 공통 문서 → 현재 승인 원본과 검토본 → 직접 비교 기준·색상 → 검수 상태 → 작업 자료 연결 순서로 작성합니다. 승인 원본과 검토본에는 용도·방향·정확한 파일 버전·approval 경로·승인 범위를 기록합니다. 검수 표에는 자동 검사·화면 관찰·실제 반복 재생·사용자 승인·엔진 결과를 구분하고 대상·근거·미확인 범위를 기재합니다. 같은 표에 함께 쓰더라도 서로 대신 통과시키지 않습니다.

이 템플릿의 승인 원본·공통 구조 연결·일러스트 선택·파츠·애니메이션·walk·최종 제출 기록 항목은 production-status.md에서 해당 work 기록을 연결합니다. 고유한 승인 예외의 내용은 character.md, 적용된 파일·승인 근거는 production-status.md에 둡니다. 공통 절차 전문을 개별 파일에 복제하지 않습니다.

과거 상태를 분리할 때는 원문을 work의 보관 문서로 보존하고 구조 설정에서 archive 역할로 등록합니다. 보관 원문 속 “현재·최신”은 당시 표현이며 현행 기준이 아닙니다. 검사·승인 기록의 원본과 이미지 해시는 그대로 유지합니다. 현재 읽기 순서는 공통 규칙·사양 → 고유 설정 → production-status.md의 승인 입력·검수 근거이며, 다음 작업은 프로젝트 remaining-work에서 확인합니다.
