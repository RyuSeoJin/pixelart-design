# 불의 여왕 — 「이그프리트」 캐릭터 소재 시트

## 제작 기준

사용자 콘셉트는 「불의 여왕 이그프리트」입니다. 사용자가 선택한 단발·군주 제복 이미지를 현재 외형 기준으로 사용합니다.
채택 원본은 `source/igfrit/igfrit-approved-design.png`입니다. 사용자 첨부 파일을 재가공 없이 복사했으며 SHA-256 일치를 확인했습니다.
공통 제작 기준은 `spec/design/pixel-art-6head-illustration-guide.html` v1.8입니다. 원본의 디자인 채택과 게임용 픽셀 규격 검수 완료는 구분합니다.
다음 수정에서는 얼굴·어깨·가슴·골반·무릎·양 발끝의 방향과 옷 중심선을 함께 검수합니다. 이그프리트의 채택 의상은 유지하며, 다른 캐릭터의 의상을 설계할 때 이 제복 구조와 비교합니다.
원본의 배경과 그림자는 그대로 보존합니다. 투명 배경·160 작업 원본·320 출력·파츠 분리·동작 프레임은 후속 제작 대상입니다.
아래 외형 표가 현재 기준이며, 장발·드레스의 이전 결과와 검수 기록은 제작 이력입니다.

## 한 줄 콘셉트

불꽃을 절제된 몸짓으로 다스리는 성인 여성 군주입니다. 화려한 화염보다 차분한 표정과 위엄 있는 예복으로 여왕임을 표현합니다.

## 규격 목표

320×320, 중심 x=160, 정수리 52, 눈 76, 턱 94, 어깨 106, 허리 148, 가랑이 178,
무릎 236, 발목 292, 발바닥 303의 기본 전신 일러스트입니다. 머리 장식을 뺀 신체는 6등신입니다.
머리카락·옷은 x=96~223를 목표로 합니다. 새 팔레트·캔버스·소품 확장 한계는 승인하거나 사양에 추가하지 않았습니다.

배포는 320 그림을 사방 96px 투명 여백으로 감싼 512×512 PNG이며 기준점은 (256,400)입니다. 그림은 확대하지 않습니다.

## 제작 결과와 검수

### 동작 제작용 전신 v4 · 2026-09-27

사용자가 idle·walk 제작에 맞는 전신을 요청해, 수정한 얼굴을 전신에 반영하고 두 부츠가 왼쪽을 향하도록 그렸습니다.
팔은 내려 두고 앞트임 사이로 두 다리가 보이도록 옷자락을 배치했습니다. 불꽃은 화면 오른쪽 손 옆으로 옮겼습니다.
기준 파일은 `source/igfrit/igfrit-base-left-320-v4.png`이며, 오른쪽은 `igfrit-base-right-320-v4.png`입니다.
두 파일은 320×320·32색·알파 0/255이고 오른쪽은 왼쪽의 정확한 좌우 반전입니다. 머리 기준선 차이 42px,
발바닥 y=303에 맞추었습니다. 기준점은 생성 원본의 시각 관찰값이며 가랑이는 추정입니다.

규칙서 v1.0 기준으로 Codex가 검수했습니다. 팔레트·크기·지면 기계 검사는 통과했고 양쪽 눈·발 방향을 확인했습니다.
최종 판정은 **수정 필요**입니다. R03·R04의 가려진 관절과 장식 범위, R06의 소매·몸통 겹침,
R20~R22의 외곽선·점 노이즈는 세부 검수가 남았습니다. 왕관 y=30~51과 불꽃 x=224 이상은 승인된 공통 범위가 아닙니다.
이 파일은 정지 전신 일러스트 초안이며 애니메이션 프레임이나 분리된 파츠가 아닙니다.
재현 과정은 `convert_fullbody_v4.py`, 검사 결과는 `fullbody-report-v4.json`, 생성 요청은 `fullbody-prompt-v4.md`에 있습니다.

### 얼굴 수정안 v3

사용자가 기존 얼굴이 너무 왼쪽을 본다고 지적하고, 첨부 예시처럼 정면에 가까운 얼굴과 걷기 동작에 어울리는 시선을 요청했습니다.
이그프리트의 얼굴은 양쪽 눈이 드러나는 얕은 3/4로 구체화했습니다. 치비 비율은 채택하지 않았습니다.
`source/igfrit/igfrit-face-study-v3.png`는 128×112의 얼굴 검토용 흉상이며 전신 완성본이 아닙니다.
생성 원본의 정수리·턱 관찰값을 기준으로 머리 높이 약 42px로 변환했습니다. 승인 팔레트 35색, 알파 0·255입니다.
`igfrit-face-comparison-v3.png`에서 기존 얼굴과 수정안의 실제 크기 및 5배 확대를 비교할 수 있습니다.
양쪽 눈과 입을 확인했으나 전신 합성·최종 규칙 검수는 아직 하지 않았습니다. 생성 요청은 `face-prompt-v3.md`, 변환 과정은 `convert_face_v3.py`에 있습니다.

- 결과: `source/igfrit/igfrit-generated-v1.png` — 내장 이미지 생성 원본, 초안입니다.
- 실제 크기: **1254×1254px**. PNG IHDR 헤더를 직접 읽어 확인했습니다. 목표 320×320과 다릅니다.
- PNG 형식: RGBA. 알파 채널이 있습니다. 가장자리의 실제 반투명도와 색 수는 아직 검수하지 않았습니다.
- R03·R19: **미통과** — 최종 픽셀 규격과 격자 정리가 필요합니다.
- R04~R06: 정밀 검수 전입니다. 그림은 왼쪽 3/4 방향이나 6등신과 기준선의 정확한 일치는 확인되지 않았습니다.
- R16~R17: 불꽃이 요청한 화면 오른쪽이 아닌 화면 왼쪽 손에 있습니다. 소재 시트와 다른 부분입니다.
- R23: 정확한 팔레트 일치·사용색 수를 확인하지 않았으므로 통과가 아닙니다.
- 검수자·일자: Codex · 2026-09-27.
- 최종 판정: **수정 필요**. 완성 일러스트로 등록하지 않습니다. 단순 크기 변경만으로 모든 규칙을 통과한 것으로 보지 않습니다.

## 2차 재시도

사용자의 재시도 요청으로 내장 이미지 편집 도구에 320×320 실제 출력을 다시 명시했습니다.
결과는 `source/igfrit/igfrit-generated-v2.png`이며 PNG IHDR 헤더 확인값은 **1254×1254**입니다.
R03·R19는 여전히 미통과입니다. 화면 왼쪽 손의 불꽃도 그대로이므로 R16~R17 수정이 남습니다.
별도 픽셀 변환과 기준선·팔레트 검수가 필요하며, 두 이미지 모두 생성 초안으로 보존합니다.
