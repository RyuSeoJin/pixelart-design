# 채택한 값

조사(`analysis/`)에서 이 프로젝트가 채택한 값만 모읍니다. 확정해서 도구가 읽는 값은
`spec/design/pixel-spec-portrait.json`(초상화)에 있고, 이 표는 그 값이 어디서 왔는지를 남깁니다. 아래 값은 모두
**초상화** 용입니다. 필드 스프라이트 값은 중앙 모듈의 치비 기본값(`pixel-style.md` §9)을 그대로 따랐습니다.

| 항목 | 채택값 | 근거 | 사양 파일 자리 |
|---|---|---|---|
| 등신 | 6등신 | 보드 6장 중 4장이 5.5~6.5등신(추정) | `anchors` (머리 단위 6배) |
| 캐릭터 키 | 252px | 보드 1번 원본 도트 키 125의 2배 — 도트 한 칸보다 작은 표현(입 · 눈 끝)을 담기 위해. 102 → 126 → 252px로 올림(2026-09-27). 중앙 범위 밖의 프로젝트 예외 | `anchors.head_top` ~ `anchors.sole` |
| 캔버스 | 320×320 | 키 252px + 머리카락 · 무기 여백. 256은 여백 4px이라 제외 | `canvas` |
| 색 수 한도 | 64색 | 보드 추정 40~60색 + 2배 해상도의 중간색 | `limits.colors_max` |
| 램프 단계 | 주 재질 5단계 · 눈 4단계 | 보드의 부드러운 전이 | `palette.ramps` |
| 외곽선 | 셀아웃 | 보드 공통 — 부위마다 다른 선 색 | 모듈 규칙 |
| 광원 | 왼쪽 위 | 보드 공통 | `light` |

키는 보드 한 장의 실측값, 나머지는 보드의 **추정값**에서 왔습니다. 첫 캐릭터를 만든 뒤 라인업 시트로 다시 봅니다.
