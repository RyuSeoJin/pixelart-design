# 채택한 값

조사(`analysis/`)에서 이 프로젝트가 채택한 값만 모읍니다. 확정해서 도구가 읽는 값은
`spec/design/pixel-spec.json`에 있고, 이 표는 그 값이 어디서 왔는지를 남깁니다.

| 항목 | 채택값 | 근거 | 사양 파일 자리 |
|---|---|---|---|
| 등신 | 6등신 | 보드 6장 중 4장이 5.5~6.5등신(추정) | `anchors` (머리 단위 6배) |
| 캐릭터 키 | 126px | 보드 1번의 원본 도트 키 125(격자 되읽기로 실측) · 머리 21px로 눈 · 입 · 손가락을 그릴 수 있음. 처음 채택한 102px은 디테일이 번져 올림(2026-09-27) | `anchors.head_top` ~ `anchors.sole` |
| 캔버스 | 160×160 | 키 126px + 머리카락 · 무기 여백 | `canvas` |
| 색 수 한도 | 48색 | 보드 추정 40~60색 | `limits.colors_max` |
| 램프 단계 | 주 재질 5단계 · 눈 4단계 | 보드의 부드러운 전이 | `palette.ramps` |
| 외곽선 | 셀아웃 | 보드 공통 — 부위마다 다른 선 색 | 모듈 규칙 |
| 광원 | 왼쪽 위 | 보드 공통 | `light` |

키는 보드 한 장의 실측값, 나머지는 보드의 **추정값**에서 왔습니다. 첫 캐릭터를 만든 뒤 라인업 시트로 다시 봅니다.
