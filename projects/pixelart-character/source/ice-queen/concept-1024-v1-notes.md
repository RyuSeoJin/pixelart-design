# 얼음여왕 여우 전신 시안 v1

내장 image_gen으로 기존 채택 v2를 참고하여 다시 그렸습니다. 흰 단발과 여우 귀, 흰 방한 튜닉,
회청색 문양·바지, 흰 부츠와 큰 꼬리를 유지했습니다. 새로운 의상 설계가 아닌 기존 디자인의 재제작입니다.
얼굴과 몸·발은 왼쪽을 향하는 얕은 3/4로 맞추며 눈을 가로로 늘리지 않는 요청을 반영했습니다.

생성 원본은 `ice-queen-concept-generated-v1.png`이며 실제 1254×1254입니다.
`normalize-concept-v1.lua`로 최근접 리샘플링하여 `ice-queen-concept-1024x1024-v1.png`를 만들고,
가시 RGB 각 채널을 최소 10으로 맞췄습니다. 원본 알파는 보존합니다.

이 파일은 고해상도 외형 검토용 시안입니다. 정확한 128 작업 격자·팔레트·6등신 기준선·256 얼굴
마스크 검수는 게임용 제작 단계에서 별도로 수행합니다. 사용자가 1024 시안을 확정했습니다. 공용 resources에는 아직 등록하지 않습니다.
128×128 도트 작업과 256×256 정지 검토본을 제작했습니다. 실행 코드는 build-still-256-v1.lua, 검사 코드는 verify_still_256_v1.py입니다. 정지본 승인은 별도로 대기합니다.
