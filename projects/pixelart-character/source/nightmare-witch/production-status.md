# 악몽 수선 마녀 제작 상태

설정 v1.28과 공통 규칙서 v1.52을 적용합니다. 현재 확정 디자인은 image-confirmed/1024/view/front.png이며 원본은 image-undecided/1024/view/front_v031.png입니다. 내장 imagegen을 사용하며 원본·프롬프트·검수 기록은 work에 보존합니다.

정면 이미지 승인 후 side_left, side_right, behind, three-quarter_left, three-quarter_right, view-three-quarter-front, view-three-quarter-head_front를 순차 제작하여 총 8종을 검토합니다. 이후 포즈 글 제안·선택 일러스트·표정·180 정지본·별도 요청된 동작 순서를 따릅니다. 정면·좌우 측면·후면·좌우 3/4 여섯 장을 image-confirmed에 저장했습니다.

## 첫 정면 검토
