# 북극여우 얼음여왕

## 현재 상태와 공통 기준

관리 식별자는 `arctic-fox`입니다. 현재는 **설정·제작 계획 확인 대기**이며, 이미지 리소스는 없습니다. 아래 외형은 재시작을 위해 확인받을 설정 초안입니다.

공통 항목은 [캐릭터 설정 템플릿](../../spec/design/character-settings-template.md), 제작·표정·승인·저장 규칙은 [제작 규칙서 v1.20](../../spec/design/pixel-art-6head-illustration-guide.html), 수치는 [필드 사양](../../spec/design/pixel-spec-field.json)과 [초상화 사양](../../spec/design/pixel-spec-portrait.json)을 따릅니다.

## 확인받을 외형

성인 여성 북극여우 부족의 얼음여왕입니다. 흰 단발과 양쪽의 짧은 땋은 머리, 곧은 흰 여우 귀, 푸른 눈, 차분한 다문 입을 유지합니다. 땋은 머리는 둥근 마디 하나와 물방울 끝 하나입니다. 귀를 제외한 약 6등신입니다.

흰 풀오버 방한 튜닉, 두꺼운 둥근 털 목깃, 넓은 소매, 회청색 넓은 바지, 흰 털 부츠를 입습니다. 소맷단·옷단에 회청색 띠와 흰 마름모 문양이 있습니다. 목깃 앞 둥근 털장식 두 개와 가슴 중앙 얼음색 마름모 펜던트를 유지합니다. 왕관·무기·목도리·망토·벨트는 추가하지 않습니다. 큰 흰 꼬리 하나는 골반 뒤에 연결되며 어두운 회보라 외곽선을 유지합니다.

각 소매 문양 한 개는 팔 바깥쪽 손목 중심선과 띠의 높이 중앙에 고정합니다. 정면·후면에서는 외곽 일부, 측면에서는 가까운 문양 한 개가 보이고, 이동용 3/4에서는 먼 팔 문양이 가려집니다. 시점마다 문양을 카메라 쪽으로 옮기지 않습니다.

## 얼굴 표정의 인상과 강도

| 표정 | 인상·강도 | 얼굴 특징 |
|---|---|---|
| 기본 | 차분하고 절제된 평소 인상 | 안정된 눈썹·눈매, 다문 입 |
| 웃음 | 은은한 기쁨 | 부드러운 눈매와 살짝 올라간 입꼬리, 입은 다문 상태 |
| 슬픔 | 조용한 슬픔 | 처진 눈매와 내려간 입꼬리 |
| 화남 | 절제되지만 분명한 분노 | 긴장된 눈썹·눈매와 단단히 다문 입 |

표정 강도는 시안 확인 대상입니다. 기본이 미소처럼 표현될 경우 웃음과 눈매·입꼬리의 차이가 읽히도록 검토합니다.

## 캐릭터별 시점 선택

일러스트용 `view-three-quarter-front`는 정면에서 화면 왼쪽으로 약 30도 회전한 전신으로 제안합니다. 시선은 같은 방향이며 기본 자세는 편안히 서서 두 팔을 내린 모습입니다.

방향별 주요 확인 요소는 팔 바깥쪽 소매 문양과 골반 뒤 꼬리의 가림입니다.

## 승인과 미정 사항

- 현재 설정과 시점 선택: 재확인 대기
- 이미지 승인: 현재 제작본 없음
- 승인된 공통 규칙 예외: 없음
- 세부 나이·개인 이름·성격의 추가 설정: 미정이며 필요할 때 제안합니다.
