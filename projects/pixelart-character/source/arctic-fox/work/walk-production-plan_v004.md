# 북극여우 walk 제작·검수 설계

## 적용 상태와 기준

사용자가 원본 비교와 프레임 조정을 포함한 반복 검수 절차를 승인했습니다. 이 문서는 제작 설계이며 이미지·동작 승인이나 검사 통과 기록이 아닙니다. 공통 규칙은 제작 규칙서 v1.35의 `walk-production-review` 절이 정본입니다.

입력은 `image-confirmed/180/view/side_left_v010.png`와 `side_right_v010.png`, 승인 근거는 `image-confirmed/approval_v008.json`입니다. 파일 경로는 캐릭터 폴더 기준입니다. 입력 해시와 실측치는 `work/walk-production-plan_v004.json`에 기록합니다. 1024의 승인 8종은 복식·가림을 보완하는 기준이며 일러스트 감정 자세를 이동용 동작에 적용하지 않습니다.

현재 좌향 수정본은 v003(16장·각 50ms)이며 검수 중입니다. 앞선 GPT 생성·국소 결합의 실패 원인은 [v002 보완 사항](walk-refinement_v002.md)에 보존합니다. 우향은 이전 2차 시도의 외형 문제가 남아 있습니다. 실패 그림을 새 외형 기준으로 채택하지 않습니다.

## 출력과 움직임 기준

- 캔버스: 180×180, 기준점: (90,171), 기본 접지 마지막 행: 170
- 좌우 독립 제작: 왼쪽을 바라보는 `walk_left`, 오른쪽을 바라보는 `walk_right`
- 현재 수정본 타이밍: 16프레임 × 50ms = 800ms, 반복 재생. 이전 비교본은 8프레임 × 100ms입니다.
- 현재 파일 번호: `frame-00`~`frame-15`. 아래 표는 8개 기준 자세이며 현재 파일의 짝수 번호에 대응합니다. 기준 자세 1·3·5·7은 현재 1·5·9·13번째 이미지입니다.
- 몸 중심은 제자리 보행 기준으로 유지합니다. 프레임마다 경계 상자를 채우도록 확대·축소하거나 발 중심에 맞춰 재배치하지 않습니다.
- 배율은 정지본에서 고정합니다. 키 156px은 정지본 실측이며 무릎 굽힘으로 달라지는 동작 높이를 매 프레임 156px로 강제하지 않습니다.
- 머리는 회전 없이 같은 측면 눈매를 유지하고, 보행에 따른 정수 픽셀 이동을 허용합니다. 눈매·얼굴·헤어 부피 변경을 상하 움직임으로 오인하지 않습니다.
- 보폭·골반 상하 이동·꼬리 반응량은 접지와 통과 자세를 실제로 구성한 뒤 측정합니다. 아직 확정되지 않은 좌표를 임의의 통과 기준으로 채우지 않습니다.

## 8프레임 동작 설계

가까운 다리는 관객 쪽 다리, 먼 다리는 반대쪽 다리입니다. 앞쪽은 캐릭터가 향하는 방향입니다. 좌우에서 부호가 바뀌어도 동작 단계는 같습니다. 가림 순서는 가까운 다리가 앞이며 화면 위치에 따라 다리의 정체성을 바꾸지 않습니다.

| 번호 | 가까운 다리 | 먼 다리 | 몸·팔 | 우선 검사 |
|---|---|---|---|---|
| 1 | 앞쪽 뒤꿈치 접지 | 뒤쪽 발끝 접지 | 가까운 팔 뒤, 먼 팔 앞 | 첫 접지, 발 길이·원근 |
| 2 | 체중을 받아 무릎을 약간 굽힘 | 뒤쪽 발이 지면에서 떨어짐 | 몸이 낮아지는 구간 | 접지 유지, 발 이탈 |
| 3 | 몸 아래에서 지지 | 무릎을 굽혀 앞으로 통과 | 팔이 중간 위치를 통과 | 공중 발·다리 가림 |
| 4 | 뒤쪽 발끝으로 밀어냄 | 앞으로 뻗어 착지 준비 | 몸이 올라오는 구간 | 다리 길이, 다음 접지 연결 |
| 5 | 뒤쪽 발끝 접지 | 앞쪽 뒤꿈치 접지 | 가까운 팔 앞, 먼 팔 뒤 | 1번과 반대 다리 지지 |
| 6 | 뒤쪽 발이 지면에서 떨어짐 | 체중을 받아 무릎을 약간 굽힘 | 몸이 낮아지는 구간 | 2번과 반대 다리 지지 |
| 7 | 무릎을 굽혀 앞으로 통과 | 몸 아래에서 지지 | 팔이 중간 위치를 통과 | 3번과 반대 다리 통과 |
| 8 | 앞으로 뻗어 착지 준비 | 뒤쪽 발끝으로 밀어냄 | 몸이 올라오는 구간 | 1번으로 이어지는 접지 |

후드·소매·꼬리는 몸의 움직임을 따라 뒤늦게 반응합니다. 과장된 꼬리 축소·확대, 옷 길이 변화, 팔과 꼬리의 충돌은 허용하지 않습니다. 가까운 다리와 먼 다리를 구별하기 위해 새 재질색이나 장식을 만들지 않습니다.

## 원본 비교 설계

| 비교 대상 | 방법 | 통과 기준 |
|---|---|---|
| 얼굴·눈 | 원본과 프레임의 머리 이동량을 맞춰 1배·정수배로 비교 | 같은 측면 눈매·입·턱·피부색, 재설계 없음 |
| 머리·귀 | 머리 기준점 정렬 후 실루엣 비교 | 같은 부피·귀 길이, 도트 밀도와 선 두께 유지 |
| 후드·튜닉 | 목·어깨·골반 부착점을 기준으로 비교 | 같은 디자인·길이 관계, 보행에 따른 천 주름만 변경 |
| 소매·옷단 자수 | 해당 옷 부위에 따라 움직이는 영역을 지정 | 문양 종류·크기 관계·부착 위치 유지, 혼입·소실 없음 |
| 손·피부 | 프레임별 손 위치에 검사 영역 지정 | 흰색 혼입·손가락 누락·외곽선 단절 없음 |

정지본의 고정 좌표 피부 검사 마스크를 움직인 손에 그대로 쓰지 않습니다. 얼굴은 이동 보정, 손·문양·접지는 프레임별 영역을 검토한 뒤 검사합니다. 전체 픽셀 일치율을 동작 품질 점수로 사용하지 않습니다.

## 실행 순서와 수정 반복

1. 입력 PNG 해시·방향·실제 배율을 확인합니다. 제작 요청 파일뿐 아니라 준비 도구가 만든 최종 프롬프트와 생성 보고서의 참고 이미지 목록을 대조합니다. 캐릭터 설명 누락·무시가 있으면 생성 전에 수정합니다.
2. sprite-gen으로 8프레임을 생성하고 정식 추출·합성 절차를 사용합니다. 도트 밀도·축소 제한 경고가 있으면 원본 비교를 먼저 수행하며 파일 생성 성공을 검수 통과로 취급하지 않습니다.
3. 1·5번 접지와 3·7번 통과 자세를 먼저 비교합니다. 교대가 맞지 않으면 그 보행 구간을 다시 제작합니다. 나머지 프레임은 두 기준 자세 사이의 이동·가림이 이어지도록 조정합니다.
4. 외형 전체가 틀리면 입력·설명·생성 경로를 바로잡아 해당 방향을 재생성합니다. 국소 오류는 Aseprite에서 해당 프레임을 수정하고 sprite-gen 합성·내보내기에 다시 연결합니다. 변경 후 원본 실행 자료와 수정본을 구분합니다.
5. 실제 추출 배율·중심 변동이 원인이라면 공통 변환을 검토합니다. 프레임별 개별 배율이나 재중앙 배치로 오류를 숨기지 않습니다. 공통 변환이 필요해도 원래 비율을 복원하는지 먼저 확인합니다.
6. 정지 비교, 전 프레임 기술 검사, 기본 속도와 느린 속도의 반복 재생, 8→1 연결, 좌우 전환을 다시 검사합니다. 부분 수정 뒤에도 전체 주기를 재검수합니다.
7. 통과하지 못한 항목은 원인과 다음 수정 방법을 기록하고 반복합니다. 재시도 횟수만으로 완료 처리하지 않습니다. 같은 원인이 반복되면 조건을 바꾸며, 도구·비용·사용자 결정이 필요한 경우 실패 결과와 다음 선택을 명시합니다.

사용자가 승인한 이 설계에서는 국소적인 동작 프레임 조정을 허용합니다. sprite-gen 안내의 일반적인 전체 행 재생성 권고보다 이번 사용자 결정이 우선합니다. 다만 프레임 복제·순서 역전·속도 변경만으로 잘못된 보행을 가리는 것은 허용하지 않습니다.

## 접지와 실제 재생

제자리 walk의 지지 발은 몸을 기준으로 뒤로 움직입니다. 지지 발의 x 좌표를 모든 프레임에서 고정하지 않습니다. 접촉하는 뒤꿈치 또는 발끝은 기본 바닥 높이에 닿고, 공중 발은 지면에서 떨어져야 합니다. 발을 굴릴 때 접촉점은 바뀔 수 있습니다.

실제 이동 속도와 결합한 미끄러짐은 엔진에서 별도로 검사합니다. 이동 속도·픽셀과 월드 단위의 관계가 정해지기 전에는 보폭과 게임 이동 속도가 일치한다고 판정하지 않습니다. 발바닥 최하단만 같다는 이유로 접지 검수를 통과시키지 않습니다.

정지 시트 관찰과 GIF 파일 생성은 실제 반복 재생 관찰이 아닙니다. 실제 재생 확인이 불가능하면 그 항목은 미검수로 유지합니다. 미검수·수정 필요가 남은 결과를 승인 후보로 제시하지 않습니다. 사용자 요청에 따라 수정 중간 결과는 방향·버전·남은 문제를 표시해 공유합니다.

## 기록·저장과 완료 판정

각 회차에 입력·출력 해시, 문제 방향·프레임·부위, 원인, 수정 방법, 변경 영역, 원본·직전 회차 비교, 반대 방향 및 전체 재검수 결과, 실제 재생 근거를 기록합니다. 공통 양식은 설정 템플릿의 walk 검수 기록 항목을 따릅니다.

최신 판정은 `work/walk-review_vNNN.json`, 수정 회차 자료는 파일명 끝 `_vNNN`으로 관리합니다. 신규 프레임·시트·미리보기·manifest는 `image-undecided/180/anim-walk/left`와 `right`에 저장하며 기존 파일을 덮어쓰지 않습니다. 기존 work 안의 실행 폴더는 생성 도구 자료로 보존합니다.

외형·프레임 기술·보행·반복·좌우 일관성 검사가 모두 통과해야 승인 후보입니다. 사용자 승인 후 동일 파일을 image-confirmed에 복사하고 승인 근거·날짜·해시를 남깁니다. 엔진 검수 후 resources 등록 여부를 판단합니다. 현재 좌향 국소 보정 8장을 제작하고 머리 지정 영역·색·알파·파일 타이밍을 검사했습니다. 전체 외형·다리 교대·접지·좌우 일관성과 실제 반복 재생은 통과하지 않았습니다. 최신 판정은 work/walk-review_v004.json입니다. 실험 결과를 공통 제작법으로 확정하지 않습니다.

## 다리 연결 수정 v002

사용자가 끊김을 지적하여 기존 생성 하체를 일괄 압축한 결합을 다음 수정의 기반으로 사용하지 않았습니다. Aseprite에서 승인 정지본의 바지·부츠 도트를 이용해 하체를 다시 수정하고, 가까운 다리와 먼 다리에 4프레임 위상차를 두었습니다. 이는 sprite-gen이 새로 생성한 보행이 아니라 Aseprite 하체 수정이며 sprite-gen은 가져오기·합성·미리보기를 담당합니다. 입력 생성 자료는 원인 비교용으로 보존합니다.

신발 기준 x 설계값은 81·86·91·96·101·98·90·82, 기준 최하단 설계값은 170·170·170·170·170·164·161·165입니다. 실제 발의 접촉점이나 공통 제한값이 아닙니다. 앞 접지·뒤 밀어내기에서 신발 끝의 높이를 최대 2px 보정했으며 수치는 이번 시험에만 적용합니다.

이전 비교 파일은 image-undecided/180/anim-walk/left의 v002이며 3배 미리보기는 work/walk-left-preview-3x_v002.gif입니다. 편집 원본은 work/walk-left_v002.aseprite입니다. work/walk-measure_v002.json으로 머리 지정 영역·팔레트·알파·합성 픽셀 일치와 고립 도트 여부를 확인했습니다. 관절 구조·접지와 반복 재생의 자연스러움은 해당 검사만으로 통과시키지 않습니다. 우향 수정·실제 재생·사용자 승인·엔진 검수는 남아 있습니다.

## 현재 수정본 v003

좌향 v003은 관절의 중간 위치를 다시 구성한 16장·각 50ms이며 총 주기 800ms는 v002와 같습니다. 발끝·뒤꿈치 높이도 중간 자세에서 이어지도록 바꾸고 꼬리 끝에는 작은 후행 이동을 적용했습니다. 같은 그림의 반복이나 알파 혼합을 사용하지 않았습니다. 원본 기준 8종·정지본·idle은 변경하지 않았습니다.

최신 출력은 image-undecided/180/anim-walk/left의 v003, 편집 원본은 work/walk-left_v003.aseprite입니다. work/walk-before-after_v003.gif는 왼쪽 v002·오른쪽 v003을 같은 주기로 보여줍니다. 독립 미리보기는 work/walk-left-preview-3x_v003.gif입니다. 검사 기록은 work/walk-measure_v003.json입니다. 머리 지정 영역·팔레트·알파·합성 일치·고립 도트 검사는 통과했지만 실제 보행의 자연스러움·반복 재생·우향·엔진 검수는 미완료입니다.
