# 사막여우 캐릭터 — 시안 제작 기록

## 상태와 범위

사용자 요청은 사막여우 부족과 사막 복식의 신규 캐릭터입니다. 이름은 미정이며 성인 여성 여행자로 시안을 제안합니다. 규칙서 v1.10을 적용합니다. 1024×1024 투명 전신 시안의 외형 승인 전에는 160 도트 원본·320 얼굴 보정·512 배포·동작으로 넘어가지 않습니다. 이 기록은 제작 후보이며 확정 소재 시트가 아닙니다.

## 복식 자료와 관찰

아래 자료는 구조 비교용이며 사진·원문을 저장소에 복사하지 않습니다. 실제 지역의 전통 의상 재현이나 역사적 정확성을 주장하지 않습니다.

## 후보와 선택

1. 긴 로브와 천 허리띠: 큰 수직 실루엣이 장점이나 기존 긴 외투와 구분이 약합니다.
2. 짧은 조끼·속상의·바지: 상하의 경계와 발목이 읽히며 보행을 위한 다리 분리가 쉽습니다. 이번 시안으로 선택합니다.
3. 어깨천과 무릎 길이 튜닉: 바람과 이동감을 줄 수 있지만 어깨를 덮는 기존 망토 구조와 가까워 이번에는 보류합니다.

이그프리트의 어깨 망토·긴 제복·굵은 가죽 벨트·긴 부츠와 비교해 겉옷 길이, 여밈, 허리 고정, 신발을 바꿉니다. 얼음여왕의 모피 후드·통짜 긴 외투·방한화와 비교해 머리 감개, 상하의 분리, 얇은 소재, 짧은 여행화로 구분합니다. 여러 지역의 장식을 임의로 조합하지 않고 기능과 큰 재단만 판타지로 해석합니다.

## 외형 제안

큰 페넥 귀 두 개, 모래 금발의 단발과 작은 땋은 머리, 청록색 눈, 모래빛 꼬리 한 개와 크림색 끝을 사용합니다. 귀를 뺀 정수리부터 발바닥까지 약 6등신이며 얼굴·몸·양 발끝 모두 화면 왼쪽을 향하는 얕은 3/4입니다. 꼬리에도 몸과 같은 외곽선을 둡니다.

남색 머리 감개, 아이보리 속상의, 황토색 짧은 조끼, 적갈색 천 허리띠, 모래색 바지, 짧은 각반과 갈색 여행화를 제안합니다. 장식은 넓은 테두리 중심이며 무기·왕관·긴 망토는 넣지 않습니다. 기존 팔레트 계열을 목표로 하며 생성 시안의 정확한 팔레트 일치는 도트 제작 단계에서 별도 검사합니다.

## 접지 계획

1024 시안에서는 전신·여백·자연스러운 접지를 검토합니다. 160 정지 원본 제작 시 접지 마지막 행 151, 320에서는 303을 맞춥니다. 오차가 있으면 정지본에서 정한 단일 이동량을 파츠·얼굴·마스크·모든 프레임에 함께 적용하고, 보행의 떠 있는 발은 개별 정렬하지 않습니다. 기본 목표를 처음부터 맞춘 새 캐릭터에는 이동량 0을 기록합니다.

## 생성과 검수

내장 image_gen 도구를 사용하며 실제 요청문은 `generation-prompt-v1.txt`에 보존합니다. 생성 결과의 크기·알파·색상 하한은 별도 파일에 실측하며 외형은 사용자 승인 대기입니다. 공용 리소스 등록과 R01~R30 전체 통과를 의미하지 않습니다.

## 도트 작업 진행과 검수

시안을 제시한 뒤 사용자가 “네 진행해주세요”라고 요청하여 다음 단계로 진행했습니다. 확정된 게임용 정지본 승인은 아직 아닙니다. `build-still-v1.py` → `finish-still-v1.lua` → `verify-still-v1.py` 순서로 재현합니다. 전신은 160 격자이며 얼굴만 320 내부 마스크에서 보정했습니다. 사용색 34개가 기존 사양 팔레트 안에 있고 알파는 0/255입니다. 얼굴 마스크 밖 변경은 0이며 512의 96px 패딩과 원본 일치를 확인했습니다.

원본 접지 행 151, 출력 303, 배포 399로 추가 위치 보정량은 0입니다. 이름·외형 최종 채택·게임용 비율과 관절·양 발 방향·꼬리 선의 전체 검수는 대기입니다. 512 파일은 검토용 포장이며 엔진 검수나 공용 리소스 등록을 마치지 않았습니다.
