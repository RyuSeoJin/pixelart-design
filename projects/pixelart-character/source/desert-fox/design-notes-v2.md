# 사막여우 v2 — 방향 수정 기록

정면 자세는 idle·walk의 진행 방향을 읽기 어려워 사용자가 수정을 요청했습니다. 제작 규칙서 v1.11 R05를 적용해 기존 의상과 캐릭터 특징을 유지하고, 얼굴·몸통·골반·무릎·두 부츠가 왼쪽을 향하는 측면에 가까운 3/4로 다시 제작했습니다.

기존 복식 후보·출처·디자인 선택은 `design-notes-v1.md`를 따릅니다. 이번 변경은 자세이며 복식의 새 선정이 아닙니다. 새 출력은 이 대화의 생성 이미지이며 Pinterest 그림을 복사하지 않았습니다.

- 시안: `desert-fox-concept-1024x1024-v2.png`
- 생성 원본: `desert-fox-generated-v2.png`
- 제작 기록: `generation-prompt-v2.txt`
- 크기·알파·색 하한 검사: `validation-v2.json`
- 검수자·검수일: Codex · 2026-09-28
- 방향 검수: 얼굴의 코와 시선, 좁아진 흉곽 앞면, 겹친 팔, 양 부츠의 왼쪽 발끝을 확인했습니다. 먼 눈을 드러내기 위해 얼굴을 정면으로 돌리지 않았습니다.
- 상태: 1024 시안 사용자 검토 대기입니다. 160 격자·320 얼굴 보정·512 포장 및 애니메이션은 이 v2에서 아직 제작하지 않았습니다. 고해상도 생성 결과를 도트 규칙 전체 통과로 처리하지 않습니다.
- 이전 버전: v1 시안과 도트 출력은 보존하며 새 방향 기준의 애니메이션 입력으로 사용하지 않습니다.

시안 방향을 확인한 뒤 R28의 기존 단계별 승인 절차에 따라 게임용 도트를 제작합니다. 접지 좌표와 프레임 공통 보정 방식은 변경하지 않습니다.
