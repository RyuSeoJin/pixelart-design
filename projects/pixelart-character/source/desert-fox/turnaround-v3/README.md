# 사막여우 v3 — 1024 시안 묶음

160·320 그림에서 보이지 않는 부위를 임의로 해석하지 않도록, 규칙서 v1.12에 따라 두 계열의 대표 그림과 삼면도를 묶었습니다. 이 묶음은 사용자 검토용이며 승인된 게임 스프라이트가 아닙니다.

## 파일과 역할

| 계열 | 대표 그림 | 삼면도 접두어 |
|---|---|---|
| 기존 정면 계열 | `desert-fox-concept-front-1024x1024-v3.png` | `desert-fox-turnaround-front-version-` |
| 측면에 가까운 3/4 계열 | `desert-fox-concept-three-quarter-1024x1024-v3.png` | `desert-fox-turnaround-three-quarter-version-` |

대표 그림은 기존 v1·v2의 파일 내용 그대로 보존했습니다. 기존 정면 계열 대표의 얕은 회전까지 임의로 바꾸지 않았습니다. 새 삼면도의 `front`, `side`, `back`은 각각 정면·왼쪽 옆면·후면이며 각 파일은 1024×1024 투명 PNG입니다. 비교판 `*-preview-v3.png`는 보기 편한 배경을 넣은 1536×512 이미지입니다. 비교판을 투명 원본으로 사용하지 않습니다.

## 외형과 새 후면 설계

기존 큰 페넥 귀·모래 금발·청록 눈·남색 머리천·황토 조끼·아이보리 블라우스·붉은 천 허리띠·헐렁한 바지·낮은 갈색 부츠·크림색 끝 꼬리를 유지합니다. 복식 출처와 구조 후보 선정은 상위 폴더의 `design-notes-v1.md`에 있습니다.

삼면도에서 파우치와 한 가닥 땋은 머리는 캐릭터 본인 왼쪽에 둡니다. 정면과 후면에서는 화면상 좌우가 바뀝니다. 머리천 뒤쪽 접힘, 조끼 등판과 천골의 꼬리 연결부는 이번에 구체화한 후면 제안으로, 사용자 확인 대상입니다. 두 계열을 의상 변형으로 취급하지 않습니다.

## 제작·검수 기록

내장 image_gen으로 계열별 삼면도 시트를 생성했습니다. 두 가닥으로 늘어난 땋은 머리, 추가 장식, 교차 여밈과 머리천 매듭의 차이는 후속 편집에서 수정했습니다. `generation-prompt.txt`가 요청 기록이고 `generated-*.png`가 채택한 생성 원본입니다. 외부 작품 이미지나 Pinterest 그림을 복사하지 않았습니다.

`format-turnarounds.lua`는 Aseprite에서 각 시점을 분리하고 같은 계열의 세 시점에 동일한 균등 배율을 적용하고 정지 삼면도 여섯 장의 접지를 1024 좌표의 같은 행에 맞춥니다. 이 처리는 동작 프레임별 접지 보정이 아닙니다. 얼굴·몸을 별도로 늘이지 않으며 알파를 유지하고 가시 RGB 각 채널을 최소 10으로 제한합니다. 출력 1024는 저장 규격이며 생성 도구가 각 시점을 처음부터 1024로 출력했다는 뜻이 아닙니다.

`verify.py`와 `validation.json`에서 파일 8장의 실제 크기·알파·색상 하한·주 실루엣 잘림, 대표 파일 보존을 확인합니다. 눈높이·머리 크기·어깨·옷의 겹침과 새 후면 구조는 시각 검토 대상입니다. 생성 결과만으로 모든 시점의 해부학적 일치나 전체 R01~R30 통과를 선언하지 않습니다.

## 다음 단계

이 묶음의 외형과 후면 구조 확인 후 160 작업 원본과 320 정면·3/4·idle 준비·walk 준비 그림을 제작합니다. 얼굴 내부만 1px 보정하며 각 그림의 마스크와 보정 레이어를 보존합니다. 이번 묶음에는 애니메이션이나 512 최종 배포본이 포함되지 않습니다.
