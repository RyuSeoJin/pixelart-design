# pixelart-character — dictionary

이 프로젝트에서만 통하는 말을 모읍니다. 범용 용어는 중앙 `core/base/dictionary.md`에, 픽셀 아트
용어는 `pixel-art` 모듈의 용어집에 있습니다. 배치 기준은 **「정의 문장에서 프로젝트 이름을 지워도
성립하는가」** — 성립하면 중앙 · 모듈, 아니면 여기입니다.
