## 다음 작업 큐

- **sprite-gen idle 시험 검토** — export/ice-queen/sprite-gen-idle-v1/idle-preview.gif와 validation.json을 확인합니다. 얼굴·발 보존은 검사했으며 호흡 강도·목 연결·꼬리 외곽선은 사용자 검토 대기입니다. 공통 idle 4프레임 사양은 유지합니다.
- **입력 기준선 정정** — 기존 320 v2 발바닥 y=301이 현행 사양 y=303과 다릅니다. 정지본의 비율·기준선 검수와 승인 후 배포본에 반영합니다. 보정 방법은 승인됐으며 접지 규칙에 따라 아래 2px을 일괄 적용한 별도 버전을 제작해야 합니다. 기존 v1은 보존합니다.

- **사막여우 검토** — source/desert-fox/turnaround-v3/ 대표 시안·삼면도와 기존 도트 검토본을 확인합니다. 외형·새 후면 구조·전체 규격 승인은 대기입니다.

- **표정 시안 검수** — 기본·웃음·슬픔·화남의 상황·강도·눈썹·눈매·입을 설정에 기록하고 기본과 겹치는 감정도 이름 없이 구별되도록 검수합니다.

- **Unreal Engine 검수** — 실제 엔진 버전·대상 플랫폼·프로젝트가 정해지면 R28에 따라 밉 개수·스트리밍 상태·화면 크기·기준점·외곽선·시트 번짐을 확인합니다. 현재는 엔진 검수 대기입니다.

- **160·320·512 규격 적용** — 기존 320 v2의 채택 표현을 기준으로 160 원본·320 얼굴 보정·512 배포를 연결합니다. 기존 생성기·검사기·공통 몸체·동작 offsets가 현행 좌표를 사용하는지 확인하고, 96px 패딩·원본 RGBA 일치·기준점 검사를 구현합니다. 사양 메타데이터만으로 도구 호환 완료를 선언하지 않습니다.

- **얼음여왕 후속 검수** — 320 v2의 눈 폭·눈매·입 표현을 유지합니다. 가려진 관절·방향·옷과 손 겹침을 검수하고 새 512 배포본을 준비합니다. 256 v1은 비교 이력, 눈을 넓힌 320 v3는 미채택으로 보존합니다.

- **얼굴 보정의 애니메이션 도구 이관** — 정지 디자인 v2의 얼굴 보정·마스크 검사는 `retouch-face-v2.lua`와 `verify_face_v2.py`에서 처리합니다. 이후 애니메이션 요청 시 `verify_delivery.py`·애니메이션 생성기에 보정 레이어 합성과 프레임별 마스크 밖 RGBA 검사를 적용합니다. 기존 전체 2배 격자 검사를 보정 얼굴에 그대로 강제하지 않습니다.

- **단계별 승인 기록 적용** — 다음 캐릭터 작업은 규칙서 v1.8의 1024×1024 시안 → 별도 승인된 320×320 정지 이미지 → 512×512 포장·배포 검수 → 요청 시 애니메이션 순서로 진행합니다. 기존 채택 외형은 유지하되 게임용 정지 이미지 승인으로 간주하지 않습니다. 단계마다 대상 파일·버전·실제 크기·승인 상태를 기록합니다.

- **얼음여왕 동작 초안 검수** — 착수 조건: 320×320 정지 이미지의 별도 승인과 애니메이션 작업 요청. 기존 초안은 보존합니다. `sprites/ice-queen-v1.aseprite`에서 가려진 옷·관절 보완, 보행 접지와 방향·R01~R30을 확인합니다. `export/ice-queen/validation.json`은 격자·색·타이밍 검사 결과이며 전체 스타일 승인과 다릅니다. 공통 생성기를 다시 돌리면 Aseprite 손질이 덮이므로 별도 버전을 사용합니다.

- **전신 방향·의상 구분 검수** — 이그프리트와 얼음여왕의 다음 수정은 규칙서 v1.8로 얼굴·몸·발의 방향과 옷 중심선을 확인합니다. 얼음여왕의 의상 재설계 시 제복의 색상 변형을 피하고 구조 후보 3개를 비교합니다. 현재 그림을 새 규칙 전체 통과로 처리하지 않습니다.

- **도트 밀도 이관** — 다음 캐릭터 수정은 규칙서 v1.8의 160×160 작업 원본부터 제작합니다. 기존 v4 전신은 이전 밀도의 초안으로 보존합니다. 얼굴·옷을 새 격자에서 정리하고 2배 확대본의 동일 RGBA 2×2px 블록을 확인하고, 얼굴 보정 후에는 마스크 밖 RGBA 일치와 승인 시안의 밀도를 확인합니다.
- **동작 제작 전 도구 이관** — 기존 변환기·공통 몸체·idle/walk 오프셋을 160 작업 격자로 옮기는 방법과 반올림을 결정합니다. 기존 오프셋의 좌표 공간을 확인하고 160 작업·320 그림·512 배포에 맞춰 변환합니다. 현재 render_grid는 메타데이터이며 자동 적용·자동 검사 기능은 없습니다.

사용자 요청 캐릭터 **불의 여왕 이그프리트**: 채택 디자인 `source/igfrit/igfrit-approved-design.png`의 단발·군주 제복을 기준으로
160 작업 원본과 투명한 320 출력을 제작하고, 관절·소매 겹침·왕관과 불꽃 범위·팔레트·발 방향을 검수합니다.
320×320 정지 이미지를 별도 승인받고 애니메이션 제작 요청이 있으면 파츠를 분리하고 가려진 부위를 보완합니다. 상세는 `spec/design/characters/igfrit.md`입니다.
이전 v4 좌우 전신은 장발·드레스의 과거 초안이므로 새 제작의 외형 기준으로 사용하지 않습니다.
