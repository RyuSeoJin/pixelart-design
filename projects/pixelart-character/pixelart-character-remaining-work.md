# pixelart-character — remaining-work

할 일의 정본입니다. 현재 승인본·검토본·검수 근거는 [북극여우 제작 상태](source/arctic-fox/production-status.md)를 확인합니다.

## 다음 작업 큐

1. **보행 반복 검수 보완** — 현재 좌우 walk의 실제 연속 프레임·마지막→첫 프레임·방향 전환을 확인합니다. 앞선 Aseprite 재생 상태·간헐 화면 확인을 전체 통과로 확대하지 않습니다.
2. **idle 반복 검수** — 승인된 좌우 idle 전체 주기·외곽선·동작 전환을 실제 확인하고 근거를 기록합니다.
3. **엔진 검수와 최종 등록** — 실제 접지·이동 속도·전환 및 공통 배포 설정을 확인하고 RESOURCE_WORKFLOW.md에 따라 등록합니다.

## 사용자 결정 대기

- 일러스트 자체의 도트화는 별도 요청 대상입니다.

## 백로그

- 기존 생성기의 180 직접 작업·방향별 외형 지원 여부는 사용 전에 확인합니다.
- 부위별 색상표를 갱신할 때 기존 v002 표와 현재 v010 입력 색상의 적용 범위를 구분합니다. 현재 승인 입력의 색을 임의로 치환하지 않습니다.
- 눈·입·손·가닥 가독성과 캐릭터 상자 밖 소품 범위는 새 캐릭터의 실제 시안으로 검토합니다.
