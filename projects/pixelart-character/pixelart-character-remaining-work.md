## 다음 작업 큐

1. **첫 캐릭터 입력 그림** — 사슴 소녀 또는 양 전사를 6등신 · 기본 자세 · 채색으로 다시 그린 그림을
   `source/{캐릭터}/`에 둡니다. 착수 조건: 아래 결정 대기의 「입력 그림 준비」
2. **3/4 정면(왼쪽 기준)에 맞춰 사양 고치기** — 먼 쪽인 화면 왼쪽(`_L`) 팔 · 다리 슬롯을 몸통 뒤로 옮기고,
   첫 캐릭터 그림에서 관절을 재서 뼈대 좌표를 비대칭으로 고칩니다. 착수 조건: 입력 그림 · 아래 「애니메이션 방식」.
   산출물: 사양 파일 · change-log
3. **첫 캐릭터 제작** — 변환 → 손으로 다듬기 → 파츠 → `.aseprite` → 내보내기.
   산출물: `sprites/{캐릭터}.aseprite` · `export/{캐릭터}/`
4. **Spine 검증** — 뼈대 JSON을 Spine에서 열어 스킨 교체가 되는지 봅니다. 결과는 중앙
   `pixel-art` 리깅 규약에 되돌려 보냅니다.

## 사용자 결정 대기

- **입력 그림 준비** — 6등신 채색 그림을 누가 어떻게 준비하는지(직접 그림 · 외주 · 기존 스케치를 다시
  그림). 큐 1번 전까지 필요합니다.
- **애니메이션 방식** — Spine 뼈대 대신 Aseprite 프레임 애니메이션으로 할지. 중앙 `pixel-art` 모듈에 프레임
  애니메이션 규칙을 더하는 일이 따라옵니다. 큐 2번 전까지 필요합니다.
- **캐릭터 색** — 사양 파일의 램프 색은 모듈 예시값입니다. 캐릭터 설정 색이 있으면 큐 3번 전에 바꿉니다.
