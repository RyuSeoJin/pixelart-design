# 배경·건물 제작 규칙

## 1. 적용 범위와 승인

180×180 도트 캐릭터와 어울리는 사이드뷰 배경·건물을 제작합니다. 2026-10-06 대화의 규칙 제안과 「네 배경 제작 규칙으로 설정하고 제작해주세요」를 승인 근거로 합니다. 이 규칙의 승인과 개별 그림의 승인은 구분합니다. UE 코드·구획·확대 설정은 이 문서를 저장하는 것만으로 변경되지 않습니다.

## 2. 버전 이름

사용자가 지정한 이름을 유지합니다. 일반적인 내외부 표현과 반대이므로 항상 보이는 모습을 함께 적습니다.

| 사용자 지정 이름 | 보이는 모습 | 엔진 연결 |
|---|---|---|
| 외부 버전 | 내부가 보이는 단면, 출입문 없음 | Cutaway |
| 내부 버전 | 건물 외관, 출입문 있음 | Facade와 공통 구조의 합성 |

완성 미리보기 두 장과 엔진용 레이어는 구분합니다. 공통 구조가 포함된 외관 완성 PNG를 그대로 반투명 앞벽으로 사용하지 않습니다.

## 3. 픽셀과 비례

캐릭터는 승인된 180×180 원본을 1배로 놓습니다. 캐릭터를 축소해서 건물에 맞추지 않습니다. 투명 여백을 포함한 프레임 크기와 실제 신체 높이는 구분합니다. 작업·앉기·운반의 손·발·도구가 차지하는 범위를 보고 가구와 통로를 정합니다.

건물 비례는 2:1·3:1처럼 정수 배수로 정합니다. 현행 식당은 아담한 2:1을 사용합니다. 가로·세로는 180의 정수 배수를 우선하며, 첫 제작 캔버스는 720×360입니다. 이는 모든 시설에 강제하는 크기가 아닙니다. 가구와 배치 좌표는 정수 픽셀을 사용합니다. 원본은 1배, 확대 검토는 최근접 2배·3배로 합니다.

외관과 단면은 동일 캔버스·중심·바닥·피벗을 공유합니다. 투명 여백을 자동 잘라내지 않습니다. 화면 구성 검토 뒤에 건물 폭을 확정합니다.

## 4. 문과 레이어

출입문·문틀·손잡이는 사라지는 앞벽에만 둡니다. 단면의 뒷벽에는 같은 출입문을 다시 그리지 않습니다. 문이 사라져도 출입 기준 좌표는 유지합니다. DoorOffset은 건물 가운데에서 문 중심까지의 정수 가로 거리입니다.

| 레이어 | 내용 | 단면 보기 |
|---|---|---|
| 공통 구조 | 지붕·양옆 기둥·기초 | 유지 |
| 실내 | 뒷벽·바닥·뒤쪽 가구 | 유지 |
| 앞쪽 가구 | 식탁·카운터의 가림 부분 | 유지 |
| 앞벽·출입문 | 외벽·문·외벽 장식 | 사라짐 |
| 외관 밤 불빛 | 창 불빛 | 앞벽과 함께 사라짐 |
| 캐릭터 참조 | 실제 승인 캐릭터 | 검토 전용, 에셋에서 제외 |

공통 부위를 앞벽에 중복해서 넣지 않습니다. 캐릭터는 실내보다 앞, 앞쪽 가구보다 뒤, 앞벽보다 뒤에 표시합니다. 모든 동작을 한 장에 그려 넣지 않습니다.

## 5. 알파와 확대

일반 그림 픽셀은 불투명, 빈 곳은 완전 투명으로 만듭니다. 앞벽 파일에 60%를 미리 적용하지 않습니다. 광원처럼 의도된 효과는 별도 레이어에서 관리합니다.

2026-10-06 확인한 UE 구현은 평소 앞벽 불투명도 60%, 단면·집중 중 0%, 단면 보기 중 다른 건물 최대 35%입니다. 월드 확대 단계는 50·100·150·200%이며 건물 선택 자동 확대는 없습니다. 제작의 정수 픽셀 규칙은 현재 UE의 비정수 표시 배율까지 보장하지 않습니다.

현재 UE 2구획 폭 480에 720 그림을 넣으면 자동 축소됩니다. 첫 식당은 연결 전 점유 폭을 720에 맞추는 별도 작업이 필요합니다. 내부 자리·문·앞쪽 소품의 좌표도 함께 맞춥니다. 기존 예시 자리 간격을 최종 치수로 복사하지 않습니다.

RTStageSprites::Place는 스프라이트 피벗보다 렌더 경계의 아래 가운데를 기준으로 배치합니다. 따라서 원본에 바닥 아래 기초나 여백이 있으면 사용자 피벗만 바꾸어 해결하지 않습니다. 캔버스·렌더 경계 보존과 바닥 오프셋을 함께 검증합니다. 첫 식당의 바닥은 y=318, 캔버스 높이는 360이므로 전체 캔버스 경계를 유지하는 조건에서 이미지 아래 가운데를 지면보다 42 낮게 두어야 합니다.

## 6. 배경

배경 패키지는 사용자 제공 `landscape-fixed-2026-10-08.md`를 정본으로 따릅니다. PNG 한 픽셀은 월드 4단위입니다. 일반 층은 1920×270, 하늘·별은 1920×894, 높은 구름은 1920×624, 바닥은 120×30, 하단 색면은 480×270으로 저장합니다. 월드 반복 폭7680과 바닥480, 지면832, 공통 카메라 배율25~100%를 유지합니다. 캐릭터와 플레이어 건물은 이 규격 대상이 아닙니다. 배경용 건물은 독립 레이어로 분리합니다.

## 7. 산출물과 검수

Aseprite 레이어 원본, 투명 PNG, 좌표 사양, 캐릭터를 포함한 검토 이미지를 함께 보관합니다. PNG에는 캐릭터를 포함하지 않습니다. 승인 캐릭터 참조는 복사하지 않고 기존 정본 경로와 해시를 기록합니다.

검수 항목은 동일 치수·피벗, 출입문이 없는 단면, 캐릭터 1배, 가구 접촉, 이동·운반 중 가림, 앞벽 100·60·0%, 밤 불빛 동반 전환, 1·2배 확대와 50·150% 축소/확대 관찰입니다. 파일 검사·시각 관찰·실제 동작 재생·UE 실행·사용자 승인은 각각 별도로 기록합니다. 없는 동작을 검수 완료로 처리하지 않습니다.

외관·단면 미술 승인 후 실제 동작과 UE를 검수하고 공용 배포를 별도로 결정합니다.
