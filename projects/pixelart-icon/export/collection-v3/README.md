# 메뉴 4종 v3 검토

`menu-before-after.png`는 위가 v2, 아래가 v3입니다. 왼쪽부터 RECRUIT·ROSTER·EDIT·SETTINGS이며, 원본을 6배 확대해 비교합니다.

- RECRUIT: 작은 인물 정보와 글줄이 있는 서류입니다.
- ROSTER: 한 명의 머리와 어깨입니다.
- EDIT: 집을 먼저 그리고 망치 손잡이와 머리를 앞에 겹쳤습니다.
- SETTINGS: 직선 톱니와 사각 중심을 사용하고 외곽의 회전·반사 대칭을 유지했습니다.

수정본은 `export/{식별자}/v3/icon-{16|32|48|64}.png`, 편집 원본은 `sprites/menu-v3/{식별자}.aseprite`입니다. 경로는 아이콘 프로젝트 루트 기준입니다. 실제 원본은 16×16이며 출력 후 보정 없이 정수배 확대했습니다.

현재 전체 구성은 v3 4종·v2 19종·v1 43종입니다. `all-64-light.png`와 `all-64-dark.png`는 현재 전체 비교판입니다. 네 수정본의 실제 크기 비교는 `menu-scales.png`에 16·32·48·64px 순서로 표시합니다. 현재 버전의 정본은 제작 목록 JSON입니다.

`validation.json`은 네 수정본의 규격과 톱니 외곽 대칭, 변경 전 현재 출력 264개 보존을 검사한 기록입니다. 외형 승인은 별도입니다. 첨부 이미지는 구성 참고만 사용했으며 저장소에 복제하지 않았습니다.
