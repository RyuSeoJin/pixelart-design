# 공통 UI v4 검토본

RECRUIT·ROSTER·감정 얼굴 2종은 홀수 지름의 원형과 좌우 대칭으로, EDIT는 일자 망치로 수정했습니다. 방향 기호 7종은 45도 사선과 90도 꼭짓점으로 정리했습니다.

- `before-after.png`: 각 칸의 위가 이전 버전, 아래가 v4입니다.
- `changed-scales.png`: 수정 12종의 실제 16·32·48·64px 출력입니다.
- `all-64-light.png`, `all-64-dark.png`: 목록이 가리키는 현재 66종입니다.
- `validation.json`: 크기·색·알파·여백·최근접 확대·얼굴 대칭·방향 각도와 이전 파일 보존 검사 결과입니다.

얼굴의 홀수 조건은 16px 작업 원본에 적용합니다. 확대 파일의 얼굴 폭이 짝수가 되는 것은 정상입니다. 메뉴·감정 5종은 최근접 확대하며 기호 7종은 각 크기로 직접 출력합니다.

원본은 `source/ui-consistency-v4/`의 좌표·Lua·SVG 및 `sprites/ui-consistency-v4/`의 Aseprite 파일입니다. 기존 원본에서 직접 수정했으며 참고 이미지 파일이나 윤곽을 복제하지 않았습니다.

자동 검사는 통과했으며 외형 승인은 대기입니다. 기존 나머지 54종은 새 공통 UI 기준 검수가 남아 있습니다. 공용 리소스 등록과 UE 반영은 하지 않았습니다.
