# 메뉴·기호 색상과 도형 v2 검토

회색 아이콘에 색상을 추가하고 체크·X를 예시처럼 도형으로 표현해 달라는 요청을 반영했습니다. 현재 전체 목록은 메뉴·기호 v2 23종과 기존 유색 v1 43종입니다. 새 외형은 검토 대기이며 공용 등록과 UE 연결은 별도입니다.

## 비교판

- `changes-light.png`와 `changes-dark.png`: 각 칸의 왼쪽은 v1, 오른쪽은 v2입니다. 64px PNG를 그대로 표시했습니다. v1만 배경에 맞는 단색으로 보이며 v2는 실제 파일의 색입니다.
- `changed-scales.png`: 각 행에 v2의 16·32·48·64px 실제 파일을 배치했습니다.
- `all-64-light.png`와 `all-64-dark.png`: 현재 66종을 제작 목록 순서대로 표시합니다.

## 제작 방식

메뉴 9종은 사물 색상과 명암을 넣은 16px 원본을 최근접 확대했습니다. 기본 제공 크기는 32px이며 네 출력 크기는 그대로입니다.

기호 14종은 도형으로 설계했습니다. 체크는 연두색, X·정지는 붉은색, 이동 기호는 파란색, 별·수정·빼기는 금색 계열입니다. 짙은 외곽선은 32px 좌표계에서 1.8px로 통일했습니다. 선의 비율을 유지하기 위해 16·32·48·64px를 도형에서 각각 직접 출력하므로 기호에는 ‘16px 최근접 확대와 일치’ 조건을 적용하지 않습니다.

기호의 편집 원본은 `source/color-geometry-v2/{식별자}.svg`이며, 동일 좌표·색·외곽선 정의는 `design.json`입니다. Aseprite의 출력 스크립트는 알파 0/255로 렌더링합니다. SVG 뷰어의 안티앨리어싱과 게임용 PNG의 표시가 다를 수 있으므로 최종 검토는 PNG로 합니다.

이번 수정은 Aseprite의 메뉴 도트 및 직접 작성한 도형 원본에서 제작했습니다. 새 이미지 생성 도구 호출은 없으며, 첨부 체크 이미지는 형태를 참고하고 저장소에 복제하지 않았습니다.

## 파일과 검사

경로는 아이콘 프로젝트 루트 기준입니다. 수정된 출력은 `export/{식별자}/v2/icon-{16|32|48|64}.png` 92개입니다. 다른 43종은 v1 출력이 현재본입니다. 개별 현재 버전과 파일 경로는 `spec/design/recordtales-icon-catalog.json`에 기록했습니다.

`validation.json`에서 현재 66종·264개 파일의 크기·색·알파·여백, 도트 52종의 최근접 확대, 기호의 방향·X 대칭 및 기존 v1 파일 264개 보존을 확인합니다. 검사 통과는 사용자 외형 승인을 대신하지 않습니다.

유색 PNG를 사용할 때 UE의 기본 런타임 색상 곱은 흰색으로 두어 파일 색을 보존해야 합니다. 이 연결 작업은 후속 큐에 기록했습니다.
